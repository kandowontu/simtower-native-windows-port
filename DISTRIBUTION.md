# Distribution boundary

GitHub releases from this repository contain source code and documentation
only. They do not contain:

- the original SimTower executable or disk image;
- extracted or repacked graphics, audio, dialogs, tables, or other resources;
- `SIMTOWER.HLP`;
- save-game fixtures copied from third parties; or
- a self-contained executable embedding any of the above.

Those files are excluded by `.gitignore` and checked by
`tools/audit_source_release.ps1` before a release is published.
Credits and trademark notices provide attribution; they do not grant a license
to distribute the original game's copyrighted material.

No license is granted here for the original SimTower material. No license has
yet been selected for the project-authored native-port source; absent an
express license, the source remains subject to the copyright holder's default
rights.
